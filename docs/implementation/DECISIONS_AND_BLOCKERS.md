## 2. Product decisions

**2026-10-25: the user approved the proposed defaults A-01 to A-08**, so they are now Decided, with **`APP_TIMEZONE=Asia/Kolkata`** and **`APP_CURRENCY=INR`** (user-supplied 2026-10-25).
